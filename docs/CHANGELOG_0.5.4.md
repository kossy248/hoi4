# Litos Union — Fortgesetzte Schwerpunkte versetzt in 0.5.4

Der Fokusbaum hatte keine eigene Position für das native Fenster
„Fortgesetzte Schwerpunkte“. Die Palette wird jetzt über
`continuous_focus_position = { x = 50 y = 2500 }` mit Abstand unter der letzten
regulären Fokusreihe positioniert. Die Position steht auch im Generator und
bleibt bei einem Neuaufbau erhalten.

Die 102 regulären Foki einschließlich Koordinaten, Voraussetzungen, Laufzeiten
und Belohnungen sind gleich geblieben. Es werden keine eigenen fortgesetzten
Foki eingeführt oder originale entfernt.

Der erzeugte Fokusbaum und das Installationspaket werden statisch und mit
künstlichen Installationsdateien geprüft. Eine Darstellungskontrolle im
laufenden HOI4 ist hier nicht möglich.

Die Entfernung der bisherigen Agitprop-Nachbildung aus 0.5.3 ist enthalten.
Die Anbindung des originalen Agitprop wartet weiterhin auf die benötigten
Originalquellen aus dem Diagnosebericht.
